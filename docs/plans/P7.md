# Phase 7: Backend Application Plan
1. Database schema and models (`backend/app/models.py`):
   - Dataset (id, sha256, path, rows, cols)
   - CandidatePlan, OperationRun, Clarification
2. API routing and endpoints (`backend/app/main.py`):
   - POST /upload (CSV/XLSX, 50MB limit, UUID storage)
   - GET /profile/{id} (row count, columns, missing values, types)
   - POST /clean/{id} (invokes ConsensusGate, returns needs_clarification or applied)
   - POST /clarify/{id} (resolves clarification, applies selected patch)
   - POST /analyze/{id} (data profiling and recommendations)
   - GET /export/{id}?format=pdf|csv|xlsx (formula injection neutralization, audit report)
3. PDF report via ReportLab & Excel audit workbook via OpenPyXL (`backend/app/export.py`).
4. Unit and end-to-end integration tests (`backend/tests/test_api.py`).
5. Verify Gate 7 and commit.
