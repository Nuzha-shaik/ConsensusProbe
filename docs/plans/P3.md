# Phase 3: Results Views (Unified Diff, Side-by-Side, Heatmap, Review Queue)

Goal: Make every single change in the dataset clearly visible and understandable with:
1. Unified Diff (edited pencil, dropped strikethrough, imputed badge)
2. Side-by-Side comparison (original vs cleaned with synchronized scroll)
3. Disagreement Heatmap (unanimous 3/3, majority 2/3, split 1/1/1)
4. Review Queue (accept / reject / undo changes)
5. Virtualized rendering tested at 50,000 rows.
