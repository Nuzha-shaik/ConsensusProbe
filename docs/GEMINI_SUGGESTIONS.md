# 6 UI Ideas for Live Demo to Project Guide

1. **Benchmark Run History & System Comparison Analytics Bar**: Side-by-side comparison of Systems A, B, C, D, E on Success Rate, Silent Error Rate, and Human Question Count from real results data.
2. **Micro-Dispute Inspector**: Concrete 3-way split view of a real row conflict (e.g. date format or duplicate ID) with measured distance d and threshold gate.
3. **Canary Sentinel Integrity Widget**: Real-time status showing injected sentinel rows, zero silent corruptions, and canary alert handling.
4. **Interactive Pareto Frontier Chart**: Visualizing Question Burden vs Task Success rate for all systems with ConsensusGate Pareto optimal point.
5. **1-Click Guide Presentation Mode (Scenarios 1, 2, 3)**:
   - Scenario 1: Clean/Unanimous Agreement ($d \le \tau_d$), auto-approved.
   - Scenario 2: Semantic Conflict ($d > \tau_d$), triggers minimal 1-click human clarification.
   - Scenario 3: Corrupt/Adversarial plan caught by Canary Sentinel.
6. **Integrity Hash (SHA-256) Before/After Drawer**: Side drawer showing SHA-256 digests, cell modifications diff, and verification trail.
