# Task T09: Audit PDF Change Highlights & Explanations (Additive Only)

## Goal
Add high-fidelity "Change Highlights" and a deterministic "What changed and why" explanation section to the Audit Report PDF, strictly preserving all existing PDF sections, text, and structure under a regression-tested toggle flag.

## Contract

### Function Interface: `frontend/src/lib/auditHighlights.ts`
```typescript
import { jsPDF } from 'jspdf';

export interface CellChangeItem {
  rowId: number;
  column: string;
  beforeVal: string;
  afterVal: string;
  opType: 'modified' | 'filled_missing' | 'deleted' | 'added';
  why: string;
  agreement: '3/3 unanimous' | '2/3 majority' | 'human-resolved' | 'conservative fallback';
}

export interface ChangeHighlightSummary {
  totalCellsChanged: number;
  totalRowsDeleted: number;
  totalRowsAdded: number;
  opCounts: Record<string, number>;
  colCounts: Record<string, number>;
  totalChangesOutsideWindow: number;
  items: CellChangeItem[]; // First 20 items
}

export interface AuditPdfOptions {
  include_change_highlights?: boolean; // default true
}

export function computeChangeHighlights(
  beforeRows: Record<string, any>[],
  afterRows: Record<string, any>[],
  patchSummary?: any,
  recordedDecisions?: any[]
): ChangeHighlightSummary;

export function renderChangeHighlightsSection(
  doc: jsPDF,
  startY: number,
  summary: ChangeHighlightSummary
): number; // Returns new final Y
```

### Deterministic "Why" Plain English Template Dictionary
```typescript
export const OPERATION_EXPLANATIONS: Record<string, (col: string, before: string, after: string) => string> = {
  modified: (col, b, a) => `Normalized format/syntax in ${col} from '${b}' to '${a}'`,
  filled_missing: (col, _, a) => `Imputed missing null value in ${col} with consensus estimate '${a}'`,
  deleted: (col, b, _) => `Removed duplicate or corrupt entity record containing '${b}'`,
  added: (col, _, a) => `Inserted standardized record entry for ${col} '${a}'`,
  formula_neutralized: (col, b, a) => `Sanitized dangerous spreadsheet formula token '${b}' to safe text '${a}'`,
  deduplicated: (col, b, _) => `Merged redundant duplicate record matching key '${b}'`,
  fallback: (col, _, __) => `Reconciled transformation in ${col} per verified consensus policy`
};
```

### Black & White Printing Legend & Symbols:
- **Modified**: Yellow fill (`[254, 240, 138]`) + Symbol prefix `[~]`
- **Filled Missing**: Cyan fill (`[224, 242, 254]`) + Symbol prefix `[+]`
- **Deleted**: Gray fill (`[241, 245, 249]`) + Strikethrough line + Symbol prefix `[-]`
- **Added**: Green fill (`[220, 252, 231]`) + Symbol prefix `[*]`

## Edge Cases & Failure Behavior
- **No changes / clean file**: If 0 cells changed, prints `"No changes recorded: dataset was already clean and compliant"`, never crashes or renders broken table.
- **Deleted rows in window**: Rendered with gray background and `[-]` prefix.
- **NaN vs Empty vs None**: Stringified distinctly (`NaN` -> `"NaN"`, `None` -> `"—"`, empty string -> `""`).
- **Numpy values**: Coerced to standard JavaScript primitives (`Number(v).toString()`).
- **Long text cells**: Truncated with ellipsis (`...`) at 28 characters to prevent layout explosion in PDF columns.
- **Unicode characters**: Escaped or normalized to standard glyphs supported by jsPDF Helvetica font.
