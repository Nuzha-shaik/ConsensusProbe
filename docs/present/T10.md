## Contract

### Playwright E2E Test Suite: `e2e/presentation.spec.ts`
1. **Test 1: Presentation Mode Bar Renders**:
   - Asserts "GUIDE PRESENTATION DEMO SUITE" banner is visible on the dashboard.
   - Asserts Scenario 1, Scenario 2, and Scenario 3 buttons exist.
2. **Test 2: Scenario 1 Execution**:
   - Clicks "Scenario 1: Unanimous Agreement".
   - Asserts status is `applied`, $d = 0.00$, questions asked = 0.
   - Asserts latency display shows `Measured Engine Latency: \d+ ms`.
3. **Test 3: Scenario 2 Dispute Trigger & Inspector**:
   - Clicks "Scenario 2: Semantic Conflict".
   - Asserts $d = 0.3800 > \tau_d$.
   - Asserts `<DisputeInspectorCard />` appears with Row #14 dispute.
   - Asserts 3 proposals (`2024-03-04`, `2024-04-03`, `2024-03-04`) are displayed.
4. **Test 4: Scenario 3 Canary Protection**:
   - Clicks "Scenario 3: Corrupt Plan Blocked".
   - Asserts `<CanaryAuditPanel />` displays `PROBEGATE SHIELD ENGAGED`.
   - Asserts 1 compromised sentinel was quarantined.
5. **Test 5: Audit PDF Download**:
   - Clicks "Audit PDF".
   - Asserts PDF download starts and file size > 50 KB.

### Python PDF Text Invariance Test: `tests/test_audit_pdf_text.py`
- Generates Audit PDF using `clientExportPdf` (via node headless runner).
- Extracts text via `pypdf`, `pdfminer`, or regex.
- Asserts required strings are present:
  - `"Legend: [~] Modified"`
  - `"Showing first 20 rows"`
  - `"What changed and why"`
  - `"Full Dataset Changes:"`
