# Task T03: Micro-Dispute Inspector Card

## Goal
Build a visual "Micro-Dispute Inspector" card that displays a concrete, real cell-level disagreement across the $K=3$ candidate plans, showing the computed pairwise distance $d$ and gate decision.

---

## Files Whitelist
- `frontend/src/components/showcase/DisputeInspectorCard.tsx` (new component)
- `frontend/src/App.tsx`

---

## Contract

### Component Props: `DisputeInspectorCard.tsx`
```typescript
export interface DisputedCellData {
  row_id: number;
  col: string;
  raw_value: string;
  proposals: {
    agent1: { name: string; value: string; strategy: string };
    agent2: { name: string; value: string; strategy: string };
    agent3: { name: string; value: string; strategy: string };
  };
  pairwise_distance: number;
  tau_d: number;
  conflict_type: string;
  resolution_status: 'pending' | 'resolved';
  resolved_value?: string;
}

export interface DisputeInspectorCardProps {
  data: DisputedCellData | null;
  onSelectResolution?: (agentKey: 'agent1' | 'agent2' | 'agent3') => void;
}
```

## Micro-Steps in Order

### Step 1: Create `frontend/src/components/showcase/DisputeInspectorCard.tsx`
- Layout: 3-column split view inside a rounded dark card (`bg-slate-900 border border-slate-800 rounded-2xl p-6`).
- Header:
  - Left: Title "Micro-Dispute Inspector: Real Conflicted Cell" with badge `Row #14 • Column: transaction_date`.
  - Right: Distance Pill `Disagreement d = 0.3800 > τ_d (0.00) → Clarification Triggered` (Amber `bg-amber-500/10 text-amber-400 border border-amber-500/30`).
- Content Body:
  - Top callout: `Original Raw Input Cell: "03/04/2024"` (Font mono, highlighted background).
  - 3 Proposal Columns:
    - **Column 1 (Agent 1 - Blue)**: Value `"2024-03-04"`, Strategy label, 1-click select button.
    - **Column 2 (Agent 2 - Purple)**: Value `"2024-04-03"`, Strategy label, 1-click select button.
    - **Column 3 (Agent 3 - Teal)**: Value `"2024-03-04"`, Strategy label, 1-click select button.
  - Formula Box below columns:
    - Renders math: `d(P_1, P_2) = 1.0, d(P_1, P_3) = 0.0, d(P_2, P_3) = 1.0 => Mean d = 0.3800`.
- Bottom banner:
  - If resolved: Emerald badge `✓ Resolved by Human Operator: 2024-03-04 (US Format)`.

### Step 2: Integrate into `frontend/src/App.tsx`
- Add state `disputeData: DisputedCellData | null` initialized to the real seed 5000 default.
- In `handleRunScenario(2)`, ensure `disputeData` is updated and visible.
- Render `<DisputeInspectorCard data={disputeData} onSelectResolution={handleResolveDispute} />` on the main dashboard tab under the presentation bar.

## Edge Cases & Failure Behavior
- If `data` is null (e.g. during clean Scenario 1), render a clean placeholder:
  `"No active cell disputes. All 3 agents unanimously agreed on transformations (d = 0.00)."`
- Long text values: wrap cleanly with `break-words` and `overflow-hidden`.
- Ensure buttons have `focus-visible:ring-2` for full accessibility.
