# Task T08: Integrity Hash (SHA-256) Before/After Slide-Out Drawer

## Goal
Implement the "Integrity hash (SHA-256), before/after" side drawer that displays dataset digests, cell change counts, and verifiable tamper-detection records without overclaiming cryptographic properties.

---

## Files Whitelist
- `frontend/src/components/showcase/IntegrityHashDrawer.tsx` (new component)
- `frontend/src/App.tsx`

---

## Contract

### Component Props: `IntegrityHashDrawer.tsx`
```typescript
export interface IntegrityHashData {
  datasetId: string;
  filename: string;
  beforeSha256: string;
  afterSha256: string;
  totalRows: number;
  totalCols: number;
  patchSummary: {
    deleted_rows: number;
    edited_cells: number;
    flagged_rows: number;
  };
  deterministicSeed?: number;
  executionTimestamp: string;
}

export interface IntegrityHashDrawerProps {
  isOpen: boolean;
  onClose: () => void;
  data: IntegrityHashData | null;
  onOpenAuditPdf?: () => void;
}
```

---

## Micro-Steps in Order

### Step 1: Create `frontend/src/components/showcase/IntegrityHashDrawer.tsx`
- Layout: Slide-over right drawer (`fixed inset-y-0 right-0 w-full max-w-md bg-slate-900 border-l border-slate-800 p-6 shadow-2xl z-50 flex flex-col`).
- Header:
  - Title: "Integrity Hash (SHA-256), Before / After" (Strictly avoiding overclaiming per Rule 4).
  - Close button with `X` icon.
- Content Sections:
  1. **Before Cleaning Ingestion Digest**:
     - Label: `Input SHA-256 (T_0)`
     - Value: 64-character hex string in monospace font with 1-click copy button.
  2. **After Cleaning Neutralized Digest**:
     - Label: `Output SHA-256 (T*)`
     - Value: 64-character hex string in monospace font with 1-click copy button.
  3. **Diff Integrity Summary**:
     - Grid showing: `Rows Deleted: N`, `Cells Edited: N`, `Rows Flagged: N`.
     - *Note*: Shares exact same patch counters as Task T09.
  4. **Reproducibility Guarantee**:
     - Seed: e.g. `20261105` / `5000`.
     - Timestamp: UTC ISO timestamp.
     - Status Badge: `Verified Deterministic Execution (Rule R7)`.
- Action Footer:
  - Button "Download Full Audit Report (PDF)" calling `onOpenAuditPdf`.

### Step 2: Wire Trigger into `frontend/src/App.tsx`
- Add state: `isIntegrityDrawerOpen: boolean`.
- In the top navigation bar or workspace action bar, add button:
  - Label: `"Integrity Hash (SHA-256)"` with `Shield` / `Hash` icon.
  - Clicking sets `isIntegrityDrawerOpen(true)`.
- Compute `beforeSha256` and `afterSha256` from `currentDataset` and `clientOriginalStore`.
- Render `<IntegrityHashDrawer isOpen={isIntegrityDrawerOpen} onClose={() => setIsIntegrityDrawerOpen(false)} data={...} />`.

---

## Edge Cases & Failure Behavior
- If dataset has not been cleaned yet: drawer shows input SHA-256 with note: *"Output digest pending consensus execution."*
- Copy to clipboard handles permission denials gracefully with fallback tooltip.
- Esc key and backdrop click close the drawer.
