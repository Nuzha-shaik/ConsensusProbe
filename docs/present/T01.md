## Micro-Steps in Order

### Step 1: Add Pydantic Models in `backend/app/models.py`
Add models:
- `SystemMetricItem(system, label, success_rate, silent_error_rate, questions_per_task, tokens, latency_sec)`
- `BenchmarkSummaryResponse(tau_d, dev_f1, total_evaluations, systems: list[SystemMetricItem])`
- `DisputedCellInfo(row_id, col, proposals: dict[str, str], reason: str)`
- `CanaryResultInfo(sentinels_injected, corruptions_detected, passed: bool, alert_details: Optional[str] = None)`
- `ScenarioExecutionResponse(scenario_id, title, seed, status, consensus_score, tau_d, questions_asked, latency_ms, dataset_preview: list[dict], patch_summary: dict, disputed_cell: Optional[DisputedCellInfo] = None, canary_result: Optional[CanaryResultInfo] = None)`

### Step 2: Implement `/api/metrics/summary` in `backend/app/main.py`
- Open and read `results/metrics.json` and `results/dev_calibration.json`.
- Compute noisy-mode averages for systems A, B, C, D, E, F (and overall).
- Attach system labels and return `BenchmarkSummaryResponse`.

### Step 3: Implement `/api/scenarios/run/{scenario_id}` in `backend/app/main.py`
- Time execution with `time.perf_counter()`.
- If `scenario_id == 1`: Load seed 1002, run consensus pipeline, assert $d = 0.0$.
- If `scenario_id == 2`: Load seed 5000, extract real contested atom between plans ($d = 0.3800$), populate `disputed_cell`.
- If `scenario_id == 3`: Load seed 5000 with canary, simulate adversarial plan mutation, detect canary corruption, return quarantined status.
- Return `ScenarioExecutionResponse` with measured `latency_ms`.

### Step 4: Write Unit Tests in `tests/test_present_api.py`
- Test `GET /api/metrics/summary`: verify HTTP 200, system count >= 6, System E has 0.0% silent error and 0.38 questions.
- Test `POST /api/scenarios/run/1`: verify HTTP 200, status `applied`, `consensus_score` == 0.0.
- Test `POST /api/scenarios/run/2`: verify HTTP 200, status `needs_clarification`, `disputed_cell` is not null.
- Test `POST /api/scenarios/run/3`: verify HTTP 200, `canary_result.passed` is false.

---

## Edge Cases & Failure Behavior
- If `results/metrics.json` is missing or corrupted: raise HTTP 500 with descriptive error detail.
- If `scenario_id` is invalid (e.g. `99`): raise HTTP 404 with `"Scenario 99 not found"`.
- Never return hardcoded mock latency; use real elapsed time in milliseconds.
