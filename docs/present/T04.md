export interface SystemMetricRow {
  system: 'A' | 'B' | 'C' | 'D' | 'E' | 'F';

export interface SystemComparisonBarProps {
  metrics: SystemMetricRow[];
  isLoading?: boolean;
  selectedSystem?: string;
  onSelectSystem?: (system: string) => void;
}

## Micro-Steps in Order

### Step 1: Create `frontend/src/components/showcase/SystemComparisonBar.tsx`
- Layout: Responsive grid/table card (`bg-white dark:bg-slate-900 border border-slate-200 dark:border-slate-800 rounded-2xl p-6 shadow-sm`).
- Top header:
  - Left: "System Benchmark Comparison (N = 300 evaluations per system, Noisy User Mode)".
  - Right: Legend pill "Rule R7 Mock Honesty Guarantee".
- Table / Cards displaying:
  - System Identifier & Name.
  - **Task Success Rate (%)**: Progress bar + value.
  - **Silent Error Rate (%)**: Highlighted red/amber if > 0.0%, emerald badge `0.0%` for E and F.
  - **Questions / Task**: Visual tick count (e.g. `0.38` with label `-62% vs System C`).
- Highlight row `E` with emerald border (`ring-2 ring-emerald-500 bg-emerald-500/5`).
- Bottom summary callout:
  *"ConsensusGate (System E) achieves 0.0% silent error rate equivalent to Always-Ask (System C), while reducing human question burden from 1.00 to 0.38 (-62.0%)."*

### Step 2: Fetch and Wire in `frontend/src/App.tsx`
- Add state: `systemMetrics: SystemMetricRow[]` initialized with the verified fallback dataset.
- In `useEffect`, attempt fetch from `${API_BASE}/api/metrics/summary`. If successful, set state with response.
- Render `<SystemComparisonBar metrics={systemMetrics} />` in the dashboard overview tab.

---

## Edge Cases & Failure Behavior
- Network failure: silently uses verified fallback dataset from `results/metrics.json` without broken UI.
- Screen resizing: table collapses into stacked cards on mobile screens (`overflow-x-auto`).
