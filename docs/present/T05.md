## Contract

### Component Props: `CanaryAuditPanel.tsx`
```typescript
export interface CanarySentinelState {
  sentinelsInjected: number;
  corruptionsDetected: number;
  status: 'passed' | 'quarantined' | 'monitoring';
  alertDetails?: string;
  injectedCells?: Array<{
    rowId: number;
    col: string;
    expectedValue: string;
    observedValue: string;
    isCompromised: boolean;
  }>;
}

export interface CanaryAuditPanelProps {
  canaryState?: CanarySentinelState;
}
```

## Micro-Steps in Order

### Step 1: Update `frontend/src/components/showcase/CanaryAuditPanel.tsx`
- Add props `canaryState?: CanarySentinelState`.
- If `canaryState.status === 'quarantined'`:
  - Render an active security alert card with red/amber border (`border-rose-500 bg-rose-500/10`).
  - Display badge: `PROBEGATE SHIELD ENGAGED • 1 UNTRUSTED PLAN INTERCEPTED`.
  - Show table of 3 sentinel cells:
    - Row 8: Laptop Pro (Match ✓)
    - Row 19: Furniture (Match ✓)
    - Row 29: Expected "Mechanical Keyboard" vs Observed "HALLUCINATED_TOKEN_XYZ" (Mismatch ✗ Alert).
  - Add text: *"Zero silent corruption reached the output dataset. The corrupted proposal was neutralized."*
- If `canaryState.status === 'passed'` or undefined:
  - Display existing default pass state: `3 Sentinels Active • 0 Silent Corruptions`.

### Step 2: Enable Scenario 3 in `frontend/src/components/showcase/PresentationModeBar.tsx`
- Replace disabled placeholder button with active button:
  - Label: `"Scenario 3: Corrupt Plan Blocked (Canary Alert)"`
  - Theme: Rose/Violet (`bg-rose-500/10 hover:bg-rose-500/20 text-rose-400 border border-rose-500/30`, `Shield` icon).
  - Triggers: `onRunScenario(3)`.

### Step 3: Wire Scenario 3 State in `frontend/src/App.tsx`
- In `handleRunScenario(3)`:
  - Receive Scenario 3 payload from backend (or `clientRunScenario(3)` fallback).
  - Set `canaryState` in `App.tsx` and pass down to `<CanaryAuditPanel canaryState={canaryState} />`.
  - Automatically scroll or highlight the Canary Audit section.
